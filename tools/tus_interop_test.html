TUS interop test (CORE-04, ≥90 MB path)

Manual harness for validating tus-js-client 4.x against the FastAPI TUS server through the live Cloudflare Quick Tunnel.

  1. Start the backend: cd backend && uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
  2. Start the tunnel: bash backend/scripts/tunnel.sh
  3. Open this page with the tunnel URL: file://$(pwd)/tools/tus_interop_test.html?endpoint=$(cat ~/.transcribe/tunnel-url)/uploads
  4. Click "Choose file" + pick a 100–200 MB media file (e.g., a long MP4)
  5. Verify the console log shows: 2 PATCHes (90 MB then remainder) AND a final HEAD reporting the upload as complete
